# MagicBook Flutter UI

A Flutter app scaffold inspired by the provided “number coloring for kids” design.

## What is included

- Multi-screen flow matching the mockup style:
  - Create screen (upload, complexity, create button)
  - Creating/progress screen
  - Color by numbers screen
  - Completion screen (save/share/print)
- Bottom navigation for Create, Gallery, and My Works.
- Purple/yellow visual style similar to the reference.

## Run

```bash
flutter pub get
flutter run
```

> Note: this implementation uses network images as placeholders and focuses on UI/flow.
